============================================
  小红书采集工具 · 使用说明
============================================

【这是什么】
基于 MediaCrawler 的小红书关键词采集工具，
按关键词搜索小红书笔记/评论，自动导出 Excel。

------------------------------------------------
【常用入口（都在本文件夹根目录，双击即可）】
------------------------------------------------
0_修改关键词.bat      → 修改要搜索的关键词（交互式输入，自动保存）
1_一键爬取并导出.bat  → 扫码登录 → 按关键词爬取 → 自动转 Excel → 打开结果
2_导出Excel.bat       → 只把已爬取的 jsonl 转成 Excel（不重新爬）
3_打开导出结果.bat    → 直接打开"导出结果"文件夹

【导出结果位置】
导出结果\小红书数据_最新.xlsx   ← 最新导出的数据，直接打开看
（原始数据在 data\xhs\ 和 data\xhs\jsonl\）

------------------------------------------------
【换新电脑时】
------------------------------------------------
1. 把整个"小红书笔记"文件夹复制到新电脑
2. 先双击"新电脑安装.bat"（需先装 Python 3.11+）
3. 再双击"1_一键爬取并导出.bat"使用

------------------------------------------------
【修改关键词】
------------------------------------------------
双击 0_修改关键词.bat，按提示输入新关键词，
多个词用中英文逗号分隔都可以（程序会自动识别），如：吉他包,吉他背带,效果器包
直接回车=不改，输入 0=退出。

⚠️ 重要：改完关键词后，必须重新运行 1_一键爬取并导出.bat，
爬虫才会按新关键词搜索；导出的 Excel 只包含当前配置关键词的数据，
不会混入之前旧关键词的历史数据。

【导出排序方式】
改 sort.txt 里的数字（保存后重新跑 2_导出Excel.bat 即可，不用重新爬）：
  1 = 最多点赞（默认）
  2 = 最多收藏
  3 = 最多评论
  4 = 最新发布

【采集数量】
每个关键词默认最多采集 300 条（约15页/每种排序），3个词 × 2种排序 最多约1800条（自动去重）。
想更多/更少，改 config\base_config.py 里的 CRAWLER_MAX_NOTES_COUNT（如 500=约25页/词）。
提示：词越多、每词条数越大、排序越多，爬取时间越长；请耐心等待窗口跑完。

【抓"最新+热门趋势"文章】
config\base_config.py 里的 SEARCH_SORTS 控制搜索排序，默认 = popularity_descending,time_descending：
  popularity_descending = 最热（点赞高优先）
  time_descending       = 最新（刚发布优先）
  general               = 综合
改完保存后重新爬即可；导出 Excel 时笔记已按点赞数从高到低排列、评论按最新排列。

------------------------------------------------
【爬取注意事项】
------------------------------------------------
1. 首次爬取会弹出浏览器二维码，需用小红书App扫码登录
2. 爬取期间请保持网络稳定，不要关闭浏览器窗口
3. 登录状态会自动保存，下次无需重复扫码
4. 配置高级参数（登录方式/是否代理等）在 config\base_config.py
